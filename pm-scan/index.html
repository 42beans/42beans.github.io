Personal desktop app

PM scan

Emails the owner a daily report about scheduled tasks and project routines.

What it does

PM scan assembles a report from local routine records and sends it to the owner's chosen Gmail address. The report helps the owner see which routines ran, which outputs arrived and which checks need attention.

Gmail access

The desktop app requests gmail.send so it can send the report from the Google account the owner authorizes. It does not request permission to read the inbox or change mailbox labels.

Where it runs

The script and saved Google sign-in run on the owner's computer. Report content may also pass through an owner-authorized connected assistant when the personal workflow uses its email fallback.
