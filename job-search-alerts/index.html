Personal desktop app

Job Search Alerts

Turns the owner's job-alert emails into organized listings and a personal daily summary.

What it does

The alert reader searches for job-board alerts, reads message content and extracts listing details such as job title, employer, location and application links. The personal workflow can label processed alerts and email a summary to the owner.

Gmail access

The desktop app requests gmail.modify to support reading alerts, managing processed labels and sending the summary. This permission is broader than reading alone. It does not permit immediate, permanent deletion that bypasses Gmail's Trash.

The alert-reading script itself only reads messages. It does not send mail, label messages or move them to Trash.

Where it runs

The reader and saved Google sign-in run on the owner's computer. Extracted listings and summaries can be processed by owner-authorized connected assistants as part of the personal job-search workflow.
